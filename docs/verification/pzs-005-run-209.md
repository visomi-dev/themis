## Implementation

- `libs/shared/src/lib/crypto/opaque-sync.ts` rejects a checkpoint whose
  envelope identity or canonical serialized bytes differ from the referenced
  live stream entry.
- `libs/shared/src/lib/crypto/opaque-sync-postgres.ts` locks the referenced
  stream row, verifies envelope identity, object SHA-256, and checkpoint bytes
  against the durable object before persisting the checkpoint.
- `apps/web/api/src/sync/opaque-sync-schemas.ts` attaches the shared 400, 401,
  403, 404, 409, and 500 error responses to every opaque-sync success path.
- `apps/web/api-e2e/src/api/sync.spec.ts` records the real HTTP checkpoint
  mismatch case and its observed `409 checkpoint_rejected` response.

- Object custody: the durable repository stores serialized envelope bytes under

  metadata hash before checkpoint acceptance; no decrypt or plaintext parser is
  used in the repository.

  ciphertext hash, record type, retention, and tombstone/checkpoint metadata;
  protected envelope fields are not selected as columns.
