# PZS-003 RUN-226 adapter isolation

Adapters expose only registered, project-bound APIs. Root `status`, `validate`,
`events`, `workspace-status`, `portfolio`, TUI, OpenCode `readState`, and
unscoped ready/timeline/aggregate paths are absent. The former `themis-view`,
`themis-tui`, and `workflow-core` delivery names are quarantined: the view/TUI
surfaces are removed and the implementation is internal-only under
`legacy-workflow-internal.ts`, never exported by the library entrypoints.

## Adapter operation-to-test negative matrix

| Operation family                                           | Required project input            | Negative/isolation test                      | Observable result                                                         |
| ---------------------------------------------------------- | --------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------- |
| ready / flow-ready                                         | CLI `--project`; tool `projectId` | missing scope; foreign project store         | parser rejects missing scope; registry rejects unknown/disabled project   |
| timeline                                                   | CLI `--project`; tool `projectId` | missing scope; foreign project               | no root timeline command; bound timeline contains only its project events |
| work item create/get/list/update/transition                | required project                  | read/update ID created in another project    | bound domain returns not-found or `UNKNOWN_PROJECT`                       |
| dependency                                                 | required project                  | dependency endpoint IDs from another project | `UNKNOWN_PROJECT`                                                         |
| epic create/list                                           | required project                  | foreign owning project                       | `UNKNOWN_PROJECT`                                                         |
| sprint propose/list/approve/activate/evidence/close/remove | required project                  | foreign sprint/revision                      | `UNKNOWN_PROJECT`                                                         |
| run start/finish and evidence                              | required project                  | foreign work item/run                        | `UNKNOWN_PROJECT`                                                         |
| review request/submit                                      | required project                  | foreign work item/review                     | `UNKNOWN_PROJECT`                                                         |
| project state/validate/backup/restore/sync                 | required project                  | unregistered, disabled, moved root           | bounded registry error; no unrelated project load                         |
| project create/list                                        | project identifier required       | root aggregate listing                       | registration plus project-bound list only                                 |

The executable adapter checks are `scripts/themis-adapter-operation-matrix.test.ts`,
`scripts/themis-cli.test.ts`, and `scripts/themis-tools.e2e.test.ts`; complete-
domain negative coverage remains in `libs/themis-workflow/src/lib/project-workflow.spec.ts`.
The adapter matrix executes every listed CLI operation family for missing,
unregistered, disabled, and moved-root project authority, plus a foreign
OpenCode read. Exact output is retained at
`docs/verification/artifacts/run-226/adapter-operation-matrix-rework.txt`.
