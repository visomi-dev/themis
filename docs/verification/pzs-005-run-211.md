# PZS-005 RUN-211 verification record

This rework preserves RUN-209 and adds the missing recovery error contract,
bounded ciphertext validation, retained artifacts, and auditable observations.

## Contract and implementation

- `GET /sync/{workspaceId}/recovery` now includes the shared `400/401/403/404/409/500`
  OpenAPI responses.
- Encrypted ciphertext is bounded at 100,000 base64url characters; oversized
  append returns `400 invalid_request`.
- The OpenAPI runner targets all `/sync/` operations, attaches valid examples
  for checkpoint, enrollment, and device recovery bodies, and records method,
  request body, path, status, and sanitized response for every sync observation.
